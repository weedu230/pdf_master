# Contributing

Thank you for your interest in contributing to this project!

## How to Contribute

1. Fork the repository.
2. Create a new branch for your changes.
3. Make your changes and test them properly.
4. Commit your changes with a clear commit message.
5. Push your branch to your fork.
6. Open a Pull Request (PR).

## Pull Requests

Please make sure your PR:

* Clearly describes what was changed.
* Explains why the change was needed.
* Does not introduce unnecessary changes.
* Has been tested before submission.
* Follows the existing project structure and coding style.

## Bug Reports

If you find a bug, you can:

* Open an Issue in the repository, or
* Contact me directly at **[mwaleedahmed256@gmail.com](mailto:mwaleedahmed256@gmail.com)**

Please include clear steps to reproduce the bug and any relevant error messages or screenshots.

## Security Issues

For security vulnerabilities, please **do not open a public Issue**. Follow the instructions in [`SECURITY.md`](SECURITY.md) and contact me directly.

## Code of Conduct

Please be respectful and professional when contributing. Constructive feedback and collaboration are always welcome.

Thank you for contributing! 🚀
