# Security Policy

## Supported Versions

Security updates are provided for the latest version of this project.

| Version        | Supported |
| -------------- | --------- |
| Latest         | ✅ Yes     |
| Older versions | ❌ No      |

## Reporting a Vulnerability

If you discover a security vulnerability, bug, or potential security issue in this project, please report it responsibly.

### Preferred Method

Please contact me directly at:

**[mwaleedahmed256@gmail.com](mailto:mwaleedahmed256@gmail.com)**

When reporting an issue, please include:

* A clear description of the vulnerability or bug
* Steps to reproduce the issue
* The expected behavior
* The actual behavior
* Any relevant error messages, logs, or screenshots
* The affected version or commit, if known
* A possible fix or recommendation, if available

Please **do not publicly disclose security vulnerabilities before they have been reviewed and addressed**.

### Pull Requests

If you have identified a security-related issue and can provide a fix, you may also submit a **Pull Request (PR)**.

For security-sensitive issues, please contact me by email first rather than immediately opening a public issue or PR.

When submitting a security-related PR:

1. Clearly explain the vulnerability.
2. Describe the changes made to fix it.
3. Explain how the fix was tested.
4. Keep the changes focused on the security issue.

## Response

I will review valid security reports and, where appropriate, work on a fix or mitigation.

Please allow reasonable time for the issue to be investigated before publicly disclosing it.

## Responsible Disclosure

I appreciate responsible disclosure and the effort of security researchers and contributors who help improve the security and reliability of this project.

Thank you for helping keep this project secure.
