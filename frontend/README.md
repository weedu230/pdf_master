# PDF Master Frontend

## Features
- Merge PDFs
- Compress PDFs
- Convert PDF to JPG
- Convert JPG to PDF
- Protect PDFs with password
- Unlock PDFs

## Installation

```bash
cd frontend
npm install
```

## Development

```bash
npm run dev
```

The app will be available at http://localhost:3000

## Build

```bash
npm run build
```

## SEO Files

- `public/sitemap.xml` - Sitemap for search engines
- `public/robots.txt` - Robots configuration

## Environment Variables

Create a `.env.local` file:

```
VITE_API_URL=http://localhost:8000/api
```
